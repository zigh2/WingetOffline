# الفحص الذاتي (Self-test)

بدل إجراء عشرات الاختبارات يدوياً ثم وصف نتائجها، يعيد البرنامج **كل ما يمكن أتمتته** على جهازك بنقرة واحدة، ويضع أمامك قائمة بما لا يفعله إلا إنسان، ثم يصدّر **تقريراً واحداً** ترسله.

* **64 فحصاً آلياً** (بينها فحوص عميقة وفحوص تحتاج إنترنت اختيارية).
* **73 خانة في قائمة يدوية** (واجهة، تثبيت فعلي، Excel، تنزيلات الإصدار...) بنتيجة وملاحظة لكل خانة تُحفظ تلقائياً.
* لا يُثبَّت ولا يُزال شيء، ومكتبتك وإعداداتك لا تتغير (انظر "ما الذي يلمسه الفحص" أدناه).

## ثلاث طرق للتشغيل

| الطريقة | متى |
|---|---|
| **صفحة Self-test في التطبيق** | الأسهل: Run all checks ← Export report. تحوي القائمة اليدوية وتفاصيل كل فحص. |
| **`wgo selftest`** | سطر الأوامر: `wgo selftest catalog.wglib --export report.md --export report.json` |
| **`scripts/run-selftest.ps1`** | سكربت PowerShell يشغّل `wgo selftest` ويضيف معلومات الجهاز (إصدار Windows، .NET، winget، الأقراص، أحجام الملفات) ويضع كل شيء في **zip واحد** للإرسال. |

```powershell
# الأبسط
.\run-selftest.ps1 -Catalog D:\catalog.wglib

# مع مثبّتاتك ومكتبتك والفحوص العميقة
.\run-selftest.ps1 -Catalog D:\catalog.wglib -InstallersFolder D:\Installers -LibraryFolder D:\Software -Deep

# مع فحص التنزيل الحقيقي (يحتاج إنترنت، ينزّل برنامجاً صغيراً)
.\run-selftest.ps1 -Catalog D:\catalog.wglib -Online
```

الخيارات المقابلة في `wgo selftest`: `--deep` و`--online` و`--installers <مجلد>` و`--library <مجلد>` (يتكرر) و`--export <ملف.md|json>` (يتكرر) و`--no-redact` و`--only <مجموعة>` و`--tools <مجلد>`. رمز الخروج 0 إن لم يفشل شيء و1 إن فشل فحص.

## ما الذي يفحصه

| المجموعة | ما فيها |
|---|---|
| **Environment** | إصدار البرنامج وحجم الملف وهل هو ملف واحد، إصدار Windows، الصلاحيات، كتابة مجلد البيانات والمؤقت، الثقافة وفاصل القوائم، إصدارات .NET المثبّتة، مجلد ذاكرة الكتالوج، الأقراص. |
| **Hashing** | xxHash64 على القيم المرجعية وبأي تقطيع، SHA256 وMD5، بصمة ملف كامل وأول جزء، سرعة الأجهزة. |
| **Export/Import** | الذهاب والإياب لصفحات Installed وUpdates وLocal بالصيغ الثلاث بكل اللغات، **رفض ملف كل صفحة في كل صفحة أخرى (18 تركيبة)**، تفاصيل CSV وإكسل، ملفات تالفة، توافق الصيغ القديمة، ملف التحديثات الذي يقرؤه `Builder pack`. |
| **Exclusions** | أنواع القواعد (مسار، لاحقة، اسم، نص، regex)، الافتراضي، التعبير الخاطئ والكارثي، متغيرات البيئة. |
| **Library** | قارئات MSI وEXE وMSIX وISO وZIP وrar/7z، **عيّنة من ملفات MSI وEXE الحقيقية على جهازك** (قراءة فقط)، دورة حياة المكتبة التزايدية (إضافة وتغيير وحذف ونقل وإعادة تسمية وقرص غير متاح وإلغاء)، سياسات البصمات، الاستثناءات أثناء الفحص، ملفات غريبة، ISO ضخم من رأسه، مطابقة المكتبة مع المثبّت، تصدير/استيراد مكتبة حقيقية، **(عميق)** فحص مجلدات مكتبتك الحقيقية في مكتبة مؤقتة مع قائمة بأضعف ما عُرف، و**(عميق)** مشي 20 ثانية على قرص النظام بالاستثناءات الافتراضية. |
| **Catalog** | إصدار الكتالوج وعمره، البحث وزمنه، كل الفلاتر، تفاصيل حزم معروفة (ترتيب الإصدارات، الروابط، البصمات)، مخطط حزمة المثبّتات (اعتماديات، معرّف مجهول، معمارية). |
| **Scan** | فحص جهازك ومطابقته، **Python وEverything وPowerToys** وغيرها بتفاصيلها، خطط الإزالة (دون تنفيذ)، مكتبتك مقابل البرامج المثبّتة، قائمة التحديثات. |
| **Installers** | فهرسة مجلد المثبّتات: ما عُرف وما لم يُعرف، خطط تثبيت صامتة، سكربت التثبيت المولَّد، سرعة المرور الثاني. |
| **Tools** | `wgo` و`Builder` الفعليان: الإصدار، `stats`، `search`، `audit-versions`، `scan --json`، `index`، `library`، `pack --dry-run`. |
| **Online** (اختياري) | ينزّل برنامجاً صغيراً بـ `Builder`، يتحقق منه، يعيد استعماله، يصلح ملفاً أفسدناه، ثم يتعرّف عليه ويبني له خطة تثبيت. |
| **UI** (في التطبيق) | ترتيب القائمة الجانبية، الإصدار الظاهر، تبديل الثيم بضغطة، الإعدادات الافتراضية. |

## ما الذي لا يمكن أتمتته (القائمة اليدوية)

النظر إلى الواجهة (مظهر فاتح وداكن، تكبير الشاشة)، **تثبيت وإزالة فعليان** وUAC، فتح التصدير في Excel، التنزيل الفعلي من صفحة الإصدار وقياس أحجامه، تشغيل النسخة الخفيفة على جهاز فيه .NET 10 فقط، النقر المزدوج على Builder، صفحات الاستيراد واللقطات، أقراص USB وOneDrive. كل خانة تحمل رقمها في `docs/TEST-PLAN.md` وخطواتها ونتيجتها المتوقعة، وتختار أمامها Pass أو Fail مع ملاحظة.

## ما الذي يلمسه الفحص

* **ملفات مؤقتة** في مجلد المؤقت (تُحذف بعد الفحص): كل الفحوص التجريبية، ومنها ملف ISO بحجم 300MB (إن توفرت مساحة 2GB).
* **مجلد البيانات**: ملف اختبار صغير يُكتب ويُحذف (ENV-4). و`selftest-manual.json` تحفظ فيه إجاباتك اليدوية.
* **قراءة فقط** من: `C:\Windows\Installer` (30 ملف MSI) و`Program Files` (80 ملف exe كحد أقصى) ومكتبتك الحقيقية (SCN-4) ومجلد المثبّتات (INS-1، ويستخدم ذاكرة البصمات الحقيقية لمجلدك).
* **مكتبتك وإعداداتك لا تتغير**. استثناءان صريحان: فحص الثيم (UI-3) يبدّل الثيم مرتين ثم يعيد إعداده الأصلي، وفحوص `wgo` تعمل بمجلد بيانات مؤقت منفصل.
* **الشبكة**: لا شيء إلا بخيار Online، وحينها ينزّل ملفاً واحداً صغيراً عبر Builder.

## الخصوصية

التقرير يحوي: إصدار البرنامج وWindows وNET، الأقراص (حروفها وأحجامها)، عدد البرامج المثبّتة ونتائج المطابقة، وأسماء وإصدارات ست برامج معروفة (Python وEverything وPowerToys و7-Zip وGit وVLC) إن وُجدت، وأسماء ملفات أضعف ما عُرف في مكتبتك (في الفحص العميق)، ومخرجات `wgo`. **اسم المستخدم واسم الجهاز ومسار ملفك الشخصي يُستبدلون تلقائياً** (`<user>` و`<machine>` و`%USERPROFILE%`) ما لم تُلغِ الخيار. راجع الملف قبل إرساله؛ هو نص عادي (Markdown) أو JSON.

## كيف تقرأ النتائج

| الحالة | المعنى |
|---|---|
| **PASS** | الفحص نجح. |
| **FAIL** | خلل حقيقي: أرسل التقرير. |
| **WARN** | شيء يستحق الانتباه (كتالوج قديم، مساحة قليلة، نسبة قراءة MSI أقل من 90%...). |
| **INFO** | معلومة تُسجَّل (الأحجام، الأزمنة، تفاصيل برامجك): هي ما أحتاجه لاختبارات مثل T2.4 وT9.1. |
| **SKIP** | تخطّاه البرنامج لسبب مكتوب (يحتاج كتالوجاً، أو Windows، أو خيار عميق/إنترنت). |

## للمطوّر

* المحرك في `WingetOffline.Core/SelfTest` (مستقل عن الواجهة): فحص جديد = سطر `new SelfCheck(...)` في الملف المناسب، مع رقم/أرقام الخطة. الفحص يجمع تأكيداته بـ `Checker` فلا يتوقف عند أول فشل، ويحوّل أي استثناء إلى FAIL مع تفاصيله.
* القائمة اليدوية في `ManualChecks.cs` مولَّدة من `docs/TEST-PLAN.md`، واختبار آلي يتحقق أن كل رقم فيها موجود في الخطة.
* اختبارات الوحدة (`SelfTestTests.cs`) تشغّل المجموعة الآلية كلها على CI وتفشل إن فشل أي فحص.
