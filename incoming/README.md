# incoming/

ضع هنا **ملف zip واحداً** يحتوي النسخة الجديدة من المشروع، ثم ادفعه (commit + push) إلى فرع `main`.
سيقوم GitHub Action تلقائياً بـ:

1. فك الضغط (ويتعامل مع وجود مجلد جذر واحد داخل الـ zip).
2. حذف كل ملفات المشروع الحالية **عدا** `.git` و `.github` و `incoming`.
3. نسخ محتويات الـ zip مكانها.
4. بناء المشروع للتأكد أنه يعمل (إن فشل البناء لا يُدفع شيء ويبقى الـ zip).
5. عمل commit بقراءة رقم الإصدار من `VERSION`، وحذف الـ zip من المجلد.

ملاحظات:
- يجب أن يحتوي الـ zip على ملف `.sln` أو مجلد `src/` وإلا يُرفض (حماية من zip خاطئ).
- ملفات `.github/` لا تُستبدل أبداً عبر هذا المسار.
- الـ zip يدخل تاريخ git؛ فاجعله صغيراً (بدون bin/obj و winget-pkgs و *.wglib).
